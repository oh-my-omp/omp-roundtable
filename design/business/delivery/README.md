# 票据交付与门禁接力

负责将单张可派发票据放上桌面，依次驱动编写者席位、外部写入与核验门禁席位完成交付，并在席位拒绝、未交接退出或外部写入失败时将票据升级交主协调器裁定；不负责跨崩溃的未决意图对账及主协调器唤醒通知。

## 依据

编写者席位与门禁席位均可能在未完成交接的情况下异常退出，且外部发布或合并写入可能被远端拒绝或结果未知（来源：宿主与远端接口运行约束，证据见附录 `evidence/github-write-uncertainty.md`）。所以 ``Delivery`RelayTicket`` 在任一席位返回 ``<Refused>`` / ``<Abandoned>`` 或外部写入未获确认时，立即调用 ``Ticket`Escalate`` 升级票据，绝不在原修订号下盲目重试或推进完成。

## 需求

前置依赖已完成的票据放上桌面后，按当轮修订号依次完成编写者席位交接、外部写入确认与门禁席位核验，并在修订号未过期时确认票据完成；任一环节失败或未交接退出时将票据升级（来源：票据接力交付需求），由 ``Delivery`RelayTicket`` 走通。
