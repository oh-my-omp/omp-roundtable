# 票据交付与门禁接力

负责将单张可派发票据放上桌面，依次驱动编写者席位、外部写入与核验门禁席位完成交付，在门禁驳回时推进返工修订号，并在席位未交接退出或外部写入失败时将票据升级交主协调器裁定；不负责跨崩溃的未决意图对账及主协调器唤醒通知。

## 依据

编写者席位与门禁席位均可能在未完成交接的情况下异常退出，门禁可能驳回当前提交，且外部写入可能被远端拒绝或结果未知（来源：宿主与远端接口运行约束，证据见附录 `evidence/host-session-and-turn.md` 与 `evidence/github-write-uncertainty.md`）。所以 ``Delivery`RelayTicket`` 在门禁返回 ``<Rejected>`` 时调用 ``Ticket`Rework`` 递增修订号供返工，在席位无法启动或返回 ``<Abandoned>``、外部写入被拒或结果未知时调用 ``Ticket`Escalate`` 升级票据。

## 需求

前置依赖已完成的票据放上桌面后，按当轮修订号依次完成编写者席位交接、外部写入确认与门禁席位核验，并在修订号未过期时确认票据完成；门禁驳回时推进返工修订号，席位弃单或外部写入未确认时将票据升级（来源：票据接力交付需求），由 ``Delivery`RelayTicket`` 走通。
