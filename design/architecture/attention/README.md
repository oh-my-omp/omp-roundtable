# 主协调器唤醒通知

负责记录主协调器已知悉的待决决策集合，并在主协调器回合结束或空闲时过滤已通知过的事项，只对新出现的待决决策唤醒主协调器；不负责改变票据或议程状态。

## 依据

主协调器在单个回合内可能连续处理多项操作，同时后台席位与定时对账也在异步推进；若每次内部状态变化都触发通知或对已知的未决事项重复发消息，主协调器会被冗余回合打断（来源：原生主会话回合调度约束）。所以 ``Attention`Observe`` 在主协调器空闲或回合结束时仅返回相较于 ``Attention`NoticeBoard`` 新增的决策，并在主协调器当回合自行消解决策后将其从 ``notified`` 中静默移除。

## 为什么

已通知决策集合只服务于抑制主协调器的重复唤醒，只用到父模块的 ``Ticket`TicketId`` 与 ``Ticket`Revision``，父模块的状态流转不需要知道某条决策是否已通知过主协调器，所以单独成为子模块。

## 语义

`Attention` 运行在协调器进程的内存中，在主协调器处于忙状态时推迟观察，待主协调器当前回合结束或处于空闲时调用一次 ``Attention`Observe``，仅当返回的新增决策集合非空时向主会话发送唤醒消息。
