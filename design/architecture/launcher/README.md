# 启动器

负责校验浏览器点击、判断议题的协调器是否在跑，并聚焦它或新开一个；不负责协调器的状态。

## 依据

写进 GitHub 议题正文的启动链接固定指向本地端口 ``Launcher`LauncherPort`` 与 tern 前端（来源：已发布链接契约）。所以端口是常量而不是设置，改了它，已发布的链接全部失效。

## 为什么

启动器没有状态，只以终端当前列出的 ``Launcher`Block`` 判断协调器是否在跑（``Launcher`Running``）：协调器随时可能被操作员在终端里关掉，启动器自己记下的协调器会在它退出后过期，挡住下一次启动。

## 语义

链接形如 `http://127.0.0.1:47591/tern/<owner>/<repo>/issues/<number>?cwd=<绝对路径>`；端口与 tern 前端不可配置，议题引用与协调器启动参数共用同一种语法。新开协调器之前，终端没有窗口连接时先在 cwd 打开窗口，协调器不在不可见的后台运行。每个请求只返回一个结局页面。
