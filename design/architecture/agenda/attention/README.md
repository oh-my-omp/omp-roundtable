# 唤醒

负责只为 Main 尚未知道、仍未解决的决策唤醒它；不负责决定哪些事算决策，也不改变议程。

## 为什么

已通知集合单独成为子模块：它只用到父模块的 ``Agenda`TicketId`` 与 ``Agenda`Revision``，议程的推进不需要知道某项决策是否已经通知过。

已通知集合不持久化（``Attention`Board``）：恢复后是新的进程与新的 Main 回合，重新通知一次全部未解决的决策正是 Main 需要的。

## 语义

只在 Main 回合结束或空闲时调用一次 ``Attention`Observe``，返回非空才唤醒 Main；Main 回合进行中不观察，它在回合内自己解决的决策因此不会唤醒它。
