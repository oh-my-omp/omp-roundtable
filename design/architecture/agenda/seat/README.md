# 席位

负责派发与结束席位、决定席位的工作空间，以及席位起不来或没交接时把票据交给 Main；不负责席位内部做什么，也不决定票据怎样前进。

## 为什么

议程不需要知道席位怎样起停，所以席位单独成为子模块，只经 ``Agenda`Except`` 与 ``Agenda`Resume`` 回到议程。

``Seat`Seats`` 只记本进程派发过的槽位，不持久化：进程结束不是席位的失败，被中断的席位在恢复后应当重做一次（``Seat`Recover``）；恢复需要操作员确认，不会无人值守地反复重做。

评判席位一律空白，产出席位接续 ``Seat`Seats.last``：评判继承产出席位的会话就失去独立性，重做的产出席位从零开始就丢掉上一轮的上下文。

## 语义

评判席位的工作空间恰是它评判的指纹所指的对象，启动前核对。接续的产出席位沿用 ``Seat`Seats.last`` 所指席位的会话与工作空间；那份工作空间保留到议程结束。

工作期被推进后，没有交接的旧席位在它下一次工具调用结束时停止，不再做旧工作期的事；交接已被接受的席位正常结束。
